# Action-quality findings, B1–B3

This is a read-only audit of the already committed native evidence. The authoritative generated detail is `action-quality-audit-B1-B3-v2.json`, with readable order listings in `ACTION-QUALITY-AUDIT-B1-B3-v2.md`. Earlier B1-only and non-v2 audit outputs were intermediate analyses; the v2 file adds requested sequence-similarity and sampled-clearance data. No new physics or acceptance-threshold change was made.

## What changed, and what did not

- B1 changed authored order rather than just renaming variants: distinct orders were 5/8 baseline, 7/8 candidate, 8/8 holdout. Within-theme pairwise median normalized token-Levenshtein similarity for family/action sequences changed from 1.000/1.000 to 0.200/0.3125 for arcade, 0.500/0.5789 to 0.000/0.0625 for foundry, and 0.6667/0.6667 to 0.250/0.1538 for signal. There are only three pairs for each three-map theme and one pair for the two-map signal theme. More difference is not automatically better composition.
- All requested verbs were present in module metadata in all eight maps of every B1–B3 arm. B1 baseline only reached active modules carrying all requested verb labels in 3/8 maps, versus 6/8 candidate and 6/8 holdout. B3 candidate/holdout reached such modules in 7/8 and 8/8. Reaching a module still does not prove its authored verbs were performed; in particular, choosing/reading/retaining an impulse cannot be read off a family name or a y range.
- B1 did not shorten its longest constant guide aims: median maximum span was 480 px baseline, 485 px candidate, and 572.5 px holdout; the maximum remained 660 px, or 4.4 nominal seconds. B2/B3 candidate median/max remained 485/660 px. B3 holdout median/max was 660/660 px. This is authored intent, not an actual constant-height cruise or lack of action: B3 candidate-706's 660 px aim contains seven observed flaps and 104.05 px of native y excursion.
- B1 native median flap rates remained close (baseline 1.557/s, candidate 1.550/s, holdout 1.543/s), and all three arms had median per-map inter-flap median 84 ticks. These whole-trace rates mix unequal death-censored observation lengths. No claim of richer cadence follows from changed order alone.
- B2 made the existing lower slider branch appear in emitted provider specs, while B1 used only upper. B2 did not improve the fixed paired survival count (4/8 to 3/8), and its holdout signal pair has identical authored family/action sequences. That is retained negative evidence, not hidden by the aggregate number of unique orders.
- The optional spring down-answer changes visible geometry/movement in some modules. B1 candidate reached three spring active ends alive with median active y range 64.84 px; B2 candidate reached three with median 219.54 px; B3 candidate reached five with median 219.54 px. These are different selected modules and carried entries, not a controlled causal comparison of a single spring. Contact remained optional: B3 candidate had two bounce contacts across five reached spring modules. One B3 candidate spring still has an active y range of only 60.65 px, so the lower-action extension does not affect every instance.
- B3 changes did not diversify paired macro order further: B2 and B3 candidate each have six distinct orders, identical pairwise authored sequence similarities, and identical maximum-guide statistics. It did materially increase observed access to the intended module geometry under this controller: light active ends reached alive rose 0/3 to 2/3, tidal active ends 4/8 authored to 6/8, reached seams 16/26 to 24/26. B3 candidate-704 still dies in light; B3 holdout reaches 26/26 seams, but five of its eight slider active ends remain beyond the 30 s observation. Eight horizon survivors are not eight full-map completions.

## Structural unused concepts versus missing relations

1. Structural unused selection: the provider already supported upper/lower slider alternatives, but B1 selected only upper. B2 draws on that existing concept. It is not a newly discovered mechanic and has no inherited qualification.
2. Structural unused degrees of freedom remain: all audited light providers still specify `rail_mode=upper`, all Cloister providers use radius 70, support ratio 1 and span 620, and all spring providers specify bounce speed 450. The source offers other masks, radii/spacing and impulse geometry, but not every advertised value combination is admitted or safe. Numeric diversity is not a goal by itself. `spin_pattern` is visual-only for filled disks, so changing it would not create a new collision/action relation.
3. Missing relational selection: every B1 candidate/holdout short map uses four or five modules, but every selected grammar outline's resolve slot is sixth. All sixteen leave resolve unused, and six end on peak. The B3 paired candidates still have zero resolve roles, with five ending on peak; B3 holdout has six peak endings. This is the narrow B4 opportunity: make complete-plan selection depend on actual phrase length so the terminal action is deliberately selected as a resolution. Relabeling the last role alone would not establish this result. Any new selection must preserve the same feasibility, source/runtime/controller/horizon and held-out protocol.
4. Missing cue/geometry and carried-state relations are a different class: B1 failures at light rails/gate tops and the tidal descent are observed trajectory/geometry mismatches, addressed separately in B3; authored family coverage alone could not repair them.
5. The suction/push families remain explicitly excluded. Their absence is policy-compliant scope, not an unused-concept defect or a reason to re-enable them.

## Curve and measurement contract

Each map's `observed.sampled_clearance.series` contains the native tick, time, x/y/vy, module id, sampled nearest lethal-body/boundary distance and body id. These use only saved body frames at 12-tick/0.1 s intervals plus the terminal frame, and `analyze_results.body_distance`; no physics or pose reconstruction is run. Any unsupported lethal-body shapes are disclosed. This is a sampled current-geometry clearance curve, not a continuous/substep lower bound, qualified input margin, calibrated human pressure or fun score.

Per-module records separately retain preparation-inclusive and active-geometry y ranges, total upward/downward end-of-tick travel, actual flap intervals/rates, contact/death events, measured seam arrival state and active-end reach state. Unobserved ranges remain null. Guide spans retain policy/module provenance so an optional spring policy does not disappear when two identical target values are merged.
