# B3 selected design references

Read the actual project SKILL.md via stage_pressure_panel.py read-reference3 before preregistering candidates. Use it as a revisable reference, not a required six-axis scorecard.

Selected axes: timing/spatial precision and carried-state continuity for late live-rail release; sustained control/recovery for the alternate low closing outlet. Retain the existing active rising-cadence section rather than chasing higher click counts. Author-informed phase data cannot measure human anticipation or choice, actual input timing tolerance, correctable spatial margin or fun. No requirement to use every axis or make every stage metric increase.

Adoption questions: does the changed collision boundary actually overlap the recorded player occupancy, do physical clocks remain continuous, do failed/tail-censored cases remain visible, and is the claimed benefit limited to the supported relation? Read B1/B2 findings and actual plots before deciding.
