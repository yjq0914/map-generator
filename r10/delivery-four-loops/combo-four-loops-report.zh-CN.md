# 四个大 loop：组合驱动整图生成器

## 结论

**完成恰好四个大 loop，交付可运行 revision 7；整图组织和上下行动关系已有进展，但仍是实验生成器。** 新增了一个真正 120 秒单世界通关见证，同时保留另一张 58.292 秒失败的长图。没有第五轮，也没有为凑通过重跑失败图。

- 宏观选择不再只取最高主题加权分；实际短图顺序和按真实长度选择的收尾有变化
- 上路 slider 保留，新增已有下路的真实入口、岛体轮廓与回升接收；不是全换成下路
- 可选 spring 的 alternate 增加接收后低答句，接触和绕行都仍存在；没有强制踩弹簧
- tidal 改中间短台及绑定真实尾沿的下降时机；light 的控制说明和接收关闭时序各自修正，区分了几何变化与虚线提示
- **普适可玩、真人趣味、视觉审美、连续安全范围和难度标定均未验证**。等频小拍、较长平缓结构、部分平 spring 旁路仍存在

## 大 loop 与小 loop 的实际区别

大 loop 必须回到整张图：上一版批量 → 诊断具体缺口 → 并行聚焦小 loop → 集成 → 同种子配对和当轮未见图 → 接受、限定或拒绝。每轮包含 8 基线、8 同种子候选、8 新种子，不能只找几个会过的组合。

小 loop 解决一个有证据的关系问题，可修改选择语法、关系变体、接缝或主题几何，并可失败。此批区别了“已有但未利用”的下路 provider，与“库里缺少”的接收后答句关系。独立小 probe 只有 5 条，不进行重型扰动网格。语法与审计小 loop 仅静态生成/分析，没有额外物理。

## 实际宏观与行动变化

### 序列相似度，不只数种类

以单位插入/删除/替换的 Levenshtein 距离计算相似度：1 − 距离 / 两序列最大长度；动作序列连接各模块实际 metadata action，保留重复。它描述重复程度，不是质量评分。

配对组内同主题的家族/动作相似度中位数，初始 r3 → 最终 r7：
- arcade：1.000/1.000 → 0.200/0.3125（3 个图对）
- foundry：0.500/0.579 → 0.200/0.235（3 个图对）
- signal：0.667/0.667 → 0.600/0.5625（只有 1 个图对，变化很有限）

最终配对 8 种顺序，未见 7 种；不要求种子绝不重复，也不把低相似度直接当好玩。B3 并未提升宏观序列差异；B4 收尾选择使部分同主题顺序重新接近。

例子：
- full701：tidal → bellows → spring → 上路 slider → cloister 回到轮廓
- full4402：tidal → bellows → spring 低答句 → 下路 slider → spring 接收
- macro5703：19 段、6 类都出现，连续完成 18 个接缝；有 returning contour、receipt、sustained outlet 的长句安排，不是固定 12 秒格子

### 真正几何变化与提示修正分开

- slider alternate 调用了原有 lower provider，phase 从分支推导；岛体按 easy/medium/hard 下移 20/30/40px，形成下降进入后至少 25/35/45px 回升至原接收口的几何要求。原上路 base 保留
- spring alternate 添加普通顶墙低答句，原弹簧与接收门不动；从离开接收口到下方答句有至少 14/24/34px 的几何下降要求。是否真的接触，以原生 bounce 事件判定，不能看最后的分支标签
- tidal 仅将中间 bank-2 宽 120→60px，真实缩短中间支撑，再由尾沿推导下降 cue；后方 roof-3 未扩大或后移
- cloister 第一圆盘没移动，所以中间圆盘提前不再带动首盘下降 cue。该修改只改作者提示，不冒称新增物理形状
- light r6 是作者虚线阈值的修正；r7 才是接收门 hold/closing 的实际时间关系变化，保留孔径和整身离开时原 1/3 开度。解析关系只覆盖理想末拍后的无输入段，不是任意入态/循环的安全证明

终段选择读取实际 4–5 段候选的最后实体与保留 guide，选接收、返回轮廓或厚门出口持续。它改变实际家族/顺序，才把支持的结尾标为 resolve；没有自动加长空白休息。

### 上下动作与净空曲线

B4/profiles 和 profiles-reviewed 保存真实 y、vy、拍动时刻与 0.1 秒采样净空曲线；JSON 同时保留对应实体、地图与轨迹 hash。实线是原生记录，虚线只是阈值。净空是保存 bodyFrames 的采样值，**不是连续/子步最小下界，也不是已标定的压力或趣味分数**。

- full701 实际 y 范围 129.61–409.99px，4/4 接缝完成，采样最小净空约 16.20px
- full4402 实际 y 范围 129.61–464.52px，4/4 接缝完成，采样最小约 14.25px；两个真实顶部接触后接收
- macro5703 实际 y 范围 129.34–444.54px，采样最小约 4.12px，仍有偏紧的光轨状态，不能宣称稳健

已写入和已实际到达的动作覆盖严格分开。read-phase/choose-layer 等标签不证明控制器或真人做了知觉判断；本控制器知道作者 guide，不能当首见玩家模型。

## 未改善与拒绝的结论

1. 最长常量 guide 段的配对中位数从初始 480px 到最终仍是 480px，最大仍 660px。它是意图而非恒定 y，但确有长平缓结构和等频微拍；没有把它说成解决
2. 上下变化及压力起伏能从真实轨迹看到，120s曲线还没有明确的三阶段递进压力，更多只是多段动作连续存在的证据；这是核心下一缺口。整体趣味/审美与真人可读性仍未测试。主题改变真实选择和结尾，但视觉主题表达仍有限
3. easy/medium/hard 是离散配方，涉及空间、时间和控制要求，并未做真人或跨控制器难度标定
4. 所有原精确合格配方保持原范围，新增组合与整图全部需要 explicit experimental；不新增合格家族或连续安全范围
5. “Bot 失败”不等于“地图无解”，“几何可通过”不等于“有趣”
